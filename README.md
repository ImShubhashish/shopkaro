# 🛒 ShopKaro — Modern E-Commerce Platform

A full-stack e-commerce showcase application built with **React**, **Ant Design**, **Tailwind CSS**, **Node.js**, **Express**, and **PostgreSQL**.

---

## 🌟 Tech Stack

### Frontend
- **Framework**: React 18+ (Vite)
- **UI Library**: Ant Design (`antd`)
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **State & Context**: React Context API (Auth, Cart, Wishlist)

### Backend
- **Runtime**: Node.js & Express.js
- **Database**: PostgreSQL
- **ORM**: Prisma ORM
- **Authentication**: JWT & HTTP-only Cookies, Bcrypt
- **Payment Processing**: Stripe API (Test Mode)

---

## 📁 Repository Structure

```text
shopkaro/
├── frontend/     # React + Vite client app (Antd + Tailwind)
└── backend/      # Node.js + Express REST API server
```
